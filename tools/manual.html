一、软件简介

「智能电源管理」用于电脑自动开关机的集中管理，支持定时关机、重启、睡眠、休眠、锁定与定时开机唤醒。全部计划由 Windows 任务计划程序执行，关闭本软件后定时任务依然生效。

功能说明
定时关机 / 重启 / 睡眠 / 休眠 / 锁定按每天 / 每周 / 工作日 / 周末 / 仅一次自动执行
定时开机（唤醒）到点自动唤醒处于睡眠 / 休眠状态的电脑
立即执行五种电源动作，带 5 秒安全确认倒计时
倒计时执行关机 / 重启由系统接管（退出程序仍生效）
开机自动启动 / 托盘驻留登录后自动运行，关闭窗口最小化到托盘
管理密码防止他人误改、误删计划
运行日志记录计划创建与执行，便于排查

二、安装与运行

安装版（推荐多台电脑统一部署）

双击 鸿升智能电源管理_1.0.8_x64-setup.exe，按提示完成安装（当前用户安装，无需管理员密码），从桌面或开始菜单启动。

便携版（免安装）

直接双击 鸿升智能电源管理.exe，可拷贝到 U 盘或任意目录使用。

软件基于 Microsoft Edge WebView2 运行时。Windows 11 已内置；Windows 10 若首次运行提示缺少组件，请安装 Evergreen WebView2 Runtime（微软官网免费下载）。

建议：以管理员身份运行

在「系统设置 → 运行权限」中点击「以管理员身份重启」。管理员模式下计划以 SYSTEM 账户执行，即使电脑停在登录界面也能正常开关机；标准模式仅在已登录时生效。

三、快速上手

1. 创建定时关机计划（示例：每天 21:30 关机）

  1. 左侧菜单点击「定时计划 → 新建计划」；
  2. 填写名称（如“晚自习后关机”），执行动作选择「关机」；
  3. 重复方式选择「每天」，时间设为 21:30；
  4. 点击「创建计划」。到时间后电脑自动关机，请提前提醒使用者保存工作内容。

2. 创建定时开机计划（示例：工作日 7:00 唤醒）

  1. 左侧菜单点击「定时开机 → 新建唤醒计划」；
  2. 动作已预设为「定时开机」，重复方式选择「工作日」，时间 07:00；
  3. 保存后，电脑处于睡眠 / 休眠状态时会自动唤醒开机。

3. 立即操作与倒计时

「立即操作」页提供五种动作的一键执行（5 秒确认倒计时，可取消）；「倒计时执行」支持 1~1440 分钟，其中关机 / 重启由 Windows 接管，退出程序仍然生效。

四、定时开机（BIOS 设置指引）

电脑完全关机（S5）时自动开机，需要主板支持并在 BIOS 中开启定时开机：

  1. 开机时连续按 Del / F2 / F10（部分品牌为 F1 / Esc）进入 BIOS；
  2. 找到「电源管理（Power Management）」；
  3. 将「Resume by RTC Alarm / Power On By Alarm / RTC 唤醒 / 定时开机」设为 Enabled；
  4. 闹钟时间设为每天首次上课前，例如 07:00；保存退出（通常按 F10）。
不同品牌菜单名称略有差异（联想、惠普、戴尔、华硕、宏碁、同方等）。建议用法：放学时对电脑执行「休眠」而非「关机」，次日用唤醒计划自动开机，省电又免去逐台开机。

五、系统设置

设置项建议
开机自动启动开启（定时计划本身不依赖本软件运行）
关闭窗口时最小化到托盘开启
管理密码设置，防止他人修改 / 删除计划
运行权限以管理员身份运行

数据目录：%APPDATA%\cn.hongsheng.power\config.json（设置页可一键打开）。删除该文件将清空全部计划与日志。

六、常见问题

Q1：到时间没有关机？
确认计划已启用（列表开关为蓝色）；确认电脑已登录（标准模式）；无人登录时请以管理员身份运行本软件；并在「运行日志」查看执行记录。
Q2：定时开机没生效？
电脑必须处于睡眠 / 休眠状态才能被软件唤醒；完全关机需在 BIOS 开启 RTC 唤醒；在「定时开机」页查看电源能力检测，若休眠不可用可一键开启。
Q3：睡眠和休眠有什么区别？
睡眠：内存保持供电，恢复快但断电丢会话；休眠：会话保存到硬盘后断电，恢复稍慢但不怕断电，适合过夜。
Q4：忘记管理密码怎么办？
关闭软件，打开数据目录删除 config.json 后重启（计划需重新创建）。
Q5：如何卸载？
安装版通过控制面板卸载；便携版直接删除文件夹，并先在设置中关闭开机自动启动。
